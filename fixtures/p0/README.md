# P0固定输入

仅用于环境和工具可行性验证，不是P1完整数据集，也不是最终保留集。

| 文件 | 来源与用途 | 预期 |
| --- | --- | --- |
| `hamburger.png` | TripoSR官方仓库`examples/hamburger.png` | 生成一份非空、有限、可独立读取的CUDA重建网格 |
| `robot.png` | 同一仓库`examples/robot.png`，不同物体 | 同上，不能用第一张的结果充数 |
| `demo_fdm_pla.ini` | 本项目编写的虚拟切片配置 | 10毫米立方体按0.2毫米层高生成50层G-code |

图片来源仓库：<https://github.com/VAST-AI-Research/TripoSR>，提交`107cefdc244c39106fa830359024f6a2f1c78871`。仓库以MIT许可发布，随附原始`TripoSR-LICENSE.txt`；不另行声称图片原始作者已被独立核实。两张源图已有透明背景，验证时按上游方法缩放前景至0.85并合成灰色不透明RGB输入，不另行下载抠图模型。

正常、边界和失败工具样例由`scripts/p0/verify_geometry.py`确定性创建：10毫米立方体、0.9毫米薄壁、两个闭合但相交的立方体壳。随机厚度采样固定种子0。工具原样调用官方3D-Print Toolbox，不自行写一个“总是通过”的几何检查器。

虚拟配置是FDM/PLA、0.4毫米喷嘴、0.2毫米层高、1.75毫米耗材，演示空间220×220×250毫米，温度200℃、热床60℃。这些数值只用于切片链路验证，没有对应实机；实际打印空间、材料牌号、温度和物理成品效果均未验证。G-code不直接发送给任何打印机。
