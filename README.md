# 2D图像到3D打印模型Agent工作流

大数据实训课程P05项目。第一版面向简单摆件，将单张物体图片转换为经过网格修复、尺寸校准、可打印性检查和人工切片确认的STL模型，并输出GLB预览与质量报告。

## 本机试用

双击根目录的[双击生成3D模型.cmd](双击生成3D模型.cmd)，选择PNG/JPEG后自动生成原始GLB，并在Blender导入查看。[使用说明与验证记录](doc/本机双击试用说明.md)列出结果目录、日志和限制。此入口为LOCAL-001附属维护，P1未启动。

唯一当前阶段保留P0已完成，2026-10-18在本机完成技术验证并由用户按清单复核通过；下一项仅P1，未经新的阶段授权不启动。已建立P0专用固定样例、验证脚本和[验证报告](doc/P0环境与工具验证.md)，两张图片CUDA重建、立方体/薄壁/自交、演示切片均已实测，真实技术结果与人工复核已分别记录；人工材料见[复核清单](doc/P0人工复核清单.md)。小组目前没有打印机，使用演示配置核对切片和G-code，物理打印效果未验证。业务API、Agent编排和前端尚未实现。
