# 2D图像到3D打印模型Agent工作流

大数据实训课程P05。第一版面向简单摆件，将单张物体图片转换为经过受限修复、尺寸校准、打印检查和人工切片确认的STL，并提供GLB预览与质量报告。

**当前路线已收缩：保留TripoSR基线和TRELLIS.2候选，复杂官方T样例仅作环境验证；后续只围绕简单摆件选一个主后端。**主要开发投入转回尺度/姿态追问、受限修复、检查分支、暂停恢复、正确停止及STL/切片证据组成的自主Agent工作流，不继续扩展模型、训练、材质或复杂机械能力。具体边界见[技术方案第1.4节](技术方案与分阶段开发计划.md#14本轮收缩与论文使用边界)。

## 运行P1离线检查

环境安装与精确版本见[CPU环境交接](locks/README.md#p1本机cpu契约环境)，无需安装torch或重建模型。已准备本机环境后，在根目录PowerShell运行：

```powershell
& runtime/envs/contracts/Scripts/python.exe -m pytest tests/unit tests/contract -q
& runtime/envs/contracts/Scripts/python.exe scripts/p1/export_schemas.py --check
& runtime/envs/contracts/Scripts/python.exe scripts/p1/check_prepared_data.py
```

[公共契约](src/image_to_3d_print/schemas/__init__.py)是唯一可执行定义，[JSONSchema](schemas/contracts-v1.schema.json)是导出文件；[数据与协议](evals/README.md)、[fixture来源](fixtures/p1/README.md)明确区分预期与实测。重建、几何、检查及导出适配器已实现；HTTP服务、Agent运行时、前端与完整交互仍待对应方向接入。
