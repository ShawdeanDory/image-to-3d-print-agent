# 桌面一键启动与连接说明

日期：2026-10-21；任务MID-LAUNCH-001；基线ff2c611。

## 1.以后如何打开

1. 在AutoDL控制台手动开机，等待实例运行；本程序不会开关机。
2. 在本项目根目录双击“启动造物工坊.exe”。
3. 等窗口显示“已连接计算服务”，程序会自动用系统默认浏览器打开http://127.0.0.1:5173/。
4. 使用时保留启动器窗口；可以最小化。“打开网页”可再次进入，“重新连接”用于断线后恢复，“查看日志”打开本机日志目录。
5. 使用结束可关闭启动器；它只回收本次创建的本机SSH/网页进程，不关闭云端API、worker或实例，也不取消业务任务。GPU实例仍按原约定由用户手动关机。

exe在项目目录中运行，需要同目录的config、scripts/desktop_launcher及已有frontend/node_modules、frontend/dist；不要只把exe单独移动到另一文件夹。可以手动创建指向它的快捷方式。本机运行exe不需要Python，不需要管理员权限；使用已有Windows.NET Framework、Node.js和OpenSSH。

源码和配置模板提交Git；exe是可重建的本机交付，不入库。队友克隆后需要自己的授权SSH公钥/配置、Node.js、前端依赖/构建，并按第4节构建exe；Git不分发私钥、模型环境或凭据。

## 2.这次为什么连不上

实际排查时SSH可以连接，但本机5173/9000没有监听；云端旧screen只有Dead记录，没有有效API/worker。开机只启动云主机，先前应用进程和本机隧道不会自动恢复。网页的“重新连接”仅重新查询接口，无法替代启动这些进程。

新启动器按顺序检查：

| 步骤 | 实际行为 |
| --- | --- |
| 预检 | 检查项目文件、Node.js、OpenSSH和现有SSH配置，不下载环境或模型 |
| 云端服务 | 使用已有公钥和严格主机验证连接同一实例；通过配置接口和worker文件锁判定存活，只补启动缺失进程 |
| SSH隧道 | 127.0.0.1:9000转发云端127.0.0.1:8000，启用保活；已有健康隧道可复用 |
| 网页 | 使用已有构建的Vite preview，127.0.0.1:5173将/api代理至9000 |
| 打开浏览器 | 同时检查页面标题及代理后的真实runtime-v1配置，再打开页面；不是先打开一个空网页就称连接成功 |
| 收尾 | 只记录并回收本次启动的本机进程；复用的服务及其他程序不被强杀 |

没有修改前后端业务状态、质量门槛或人工确认，不增加公网映射，不提交新任务。已有浏览器会按自身保存的任务ID恢复旧任务，看到旧模型不表示启动器又生成了一次。启动worker会按已有队列规则处理用户此前已提交的任务，启动器本身不提交重建。

## 3.配置、错误和日志

默认模板为[launcher.example.json](../config/launcher.example.json)，本机可选覆盖文件runtime/launcher/config.json。仅配置SSH配置相对路径、别名、云端项目、现有部署和两个端口；不在其中填写密码、私钥或API令牌。SSH主机/端口来自原runtime/ssh/p2a_config；AutoDL登录地址变化时修改自己的SSH配置。

默认项目为/root/autodl-tmp/image-to-3d-print-agent，部署deployments/official-20261021-01；端口5173/9000。启动器不静默切换后端或部署、不关闭占用端口的其他进程。

| 提示 | 处理 |
| --- | --- |
| SSH/云端未就绪 | 核对开机状态、当前SSH地址/端口、公钥及主机记录；严格验证失败时由操作者核对，不自动信任新主机 |
| 缺少项目文件/Node/OpenSSH | 恢复对应项目目录或既有依赖；不会自动安装 |
| 9000端口占用或旧隧道断开 | 关闭自己遗留的旧隧道，或修改本机启动配置；程序不强杀其他进程 |
| 5173被其他服务/错误代理占用 | 关闭自己此前单独开的网页服务，或修改启动端口 |
| 云端API/worker启动超时 | 查看云端runtime/launcher/api.log或worker.log；不通过重装模型掩盖错误 |
| API要求服务访问凭据 | 先核对已有API认证配置；启动器不读取、取消或绕过认证 |

本机日志为runtime/launcher/launcher-时间.log，最近结果runtime/launcher/last-result.json。窗口每10秒做一次健康检查，断线显示状态，手动点击“重新连接”；不会无限后台重试或自动支付/开机。关闭启动器不等于AutoDL停机。
