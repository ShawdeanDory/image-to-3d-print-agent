## 4.可复现命令

在项目根目录，用已有Windows Python运行：

```powershell
runtime/envs/backend/Scripts/python.exe -m unittest discover -s tests/desktop_launcher -p test_team_package.py -v
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/desktop_launcher/TeamSetupTests.ps1
runtime/envs/backend/Scripts/python.exe -m pytest tests/contract/test_desktop_launcher.py -q
```

C#用Windows自带Framework64/v4.0.30319/csc.exe，将Launcher.cs及DesktopLauncherTests.cs的绝对路径传入，指定`/main:DesktopLauncherTests`、原4项程序集引用和runs内独立输出；不覆盖用户正在运行的根目录exe。

打包前在frontend执行npm run build；准备与Node版本匹配的官方LICENSE文件。打包命令如下，node.exe和LICENSE为本机已准备文件路径，known_hosts仅提取服务器公钥：

```powershell
runtime/envs/backend/Scripts/python.exe scripts/desktop_launcher/package_team.py --output runs/新的启动包目录 --node "已有Node的node.exe完整路径" --node-license "对应Node版本的LICENSE路径" --known-hosts runtime/ssh/known_hosts
runtime/envs/backend/Scripts/python.exe tests/desktop_launcher/team_bundle_smoke.py "runs/新的启动包目录.zip"
```

Node许可证来源为https://raw.githubusercontent.com/nodejs/node/v24.14.1/LICENSE；Vite及依赖各自许可证随运行目录保留，前端React/ReactDOM/Three许可证单列，HDR资源原有许可证随dist保留。
