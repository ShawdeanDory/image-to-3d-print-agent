# 打印修复算法参考与接入

日期：2026-10-29。目标是可检查、可切片的打印副本，不以材质观感代替几何。用户已允许必要重网格，原始彩色GLB完整保留、不重烘焙；物理打印暂无实际设备证据。

以上资料有助于选择算法，不代表已在本项目验证。仅实际运行并通过保形、逐项几何及切片检查的方法才接入默认路径。

## 2.本轮验证顺序与接受门槛

1. 保存旧GLB、原始检查与旧修复拒绝结果；仅在独立打印副本操作。
2. 固定正常、复杂孔、相交/非流形、薄壁、多个主要组件、缺依赖及超时样例。
3. 每个算法候选重新计算几何与三视图，拒绝明显丢部件/外形变化；水密单项不能决定接受。
4. 接受的版本执行同一Blender/Toolbox检查，记录未执行项，再导出STL并独立读回。
5. 切片验证使用声明版本与演示FDM/PLA配置；实际分层/挤出记录必须非空。没有实际打印机，不把演示切片当设备适配或实物打印成功。

## 3.实际试验记录

- MeshFix0.18.1已在独立运行时下载并与官方PyPI SHA256核对。已有95877面网格8.007秒修复后62300面，边界/非流形均为0、水密，但组件20→1，宽148.337→130.749mm、深80.700→70.588mm。即使关闭remove_smallest_components和joincomp，仍有明显形状损失，因此不直接作为默认通过结果，原件保持。
- 用户将范围缩至一个10～15cm简单摆件。固定已有鸭图GLB，MeshFix补孔及MeshLib闭合包含判定填实内腔后，完整检查仍有31处薄壁与底面失败。第二轮用0.7mm有限偏移、0.35mm体素/≤0.06mm简化误差及0.5mm底部切平，切口经局部CutAndFill修复后逐项通过，悬垂仍需支撑。
- 最终166738面、高120mm、最大外形尺寸变化0.403%；本机PrusaSlicer2.9.6实际切片通过。MeshLib-Core/PyMeshFix在云端隔离使用，未复制库源码/二进制入库，未改网页生产路径；Paint3D/CGAL/Alpha Wrapping仅参考，未宣称复现或已接入。详见[单件验收](小摆件打印转换与展示件验收.md)。
