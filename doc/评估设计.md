## 1.数据集设计

后续至少准备30个固定任务，按物体或来源分组，避免同一物体的不同图片进入开发集和保留集。下面数量是计划，不代表数据已经收集。

| 划分 | 数量 | 用途 |
| --- | --- | --- |
| 开发/提示样例集 | 10例：6正常＋4异常/边界 | 调整预处理、提示和修复规则，不训练重建模型 |
| 开发评估集 | 10例：6正常＋4异常/边界 | 每轮重复评估，观察改进及回归 |
| 最终保留集 | 10例：6正常＋4异常/边界 | 版本冻结后首次执行，不用于挑选参数和提示 |

异常任务覆盖未知尺度、遮挡、复杂背景、损坏文件、不适用物体和工具错误；另用固定几何fixture覆盖孔洞、非流形边/顶点、反向法线、自交、薄壁、已知斜面及多个组件。

每例记录`case_id`、`dataset_version`、来源/许可、所属物体、输入、预期行为、目标高度、打印配置和参考网格情况。没有参考网格时对应误差为未知，不能填0。P0最小样例单独编号，不能据其少量通过宣称完整评估通过。

## 2.第一版最终验收门槛

P1明确计算口径，P2完成基线实测后冻结阈值。调整必须在保留集首次执行前说明原因和版本，不根据保留集结果事后降低标准。

| 指标 | 口径与门槛 |
| --- | --- |
| 正常任务成功率 | 全部18个正常任务至少成功15个，且保留集6个正常任务至少成功5个；成功定义见技术方案第1.3节 |
| 缺尺度处理 | 所有缺尺度测试主动请求尺度，未知时不标为真实毫米尺寸，不完成定标交付 |
| 尺度误差 | 成功任务导出重读后的高度误差不超过`max(0.5毫米,目标高度×1%)`；只验证定标，不代表完整形状准确 |
| 拓扑质量 | 成功任务水密，边界边、非流形边/顶点及检出自交面数均为0，法线检查通过 |
| 薄壁检出 | 0.6毫米与0.9毫米fixture被发现，1.6毫米正常fixture通过；临界样例标为不确定并复核 |
| 检查完整性 | 成功任务必需检查实际执行率100%，工具不可用不能记为通过 |
| 文件可读率 | 成功任务GLB与STL独立重读成功率100%，重读尺寸符合要求 |
| 轮廓一致性 | 固定相机、蒙版及归一化方法后，正常成功样例轮廓IoU中位数至少0.70；口径在P1定义、P2实测冻结 |
| 修复保形 | 修复后IoU相对原始重建下降不超过0.05；超过时说明并请求确认 |
| 切片验证 | 至少5个不同对象完成固定软件/配置的分层验证，含至少1个经过缺陷修复的对象；每个成功任务均须有其自身网格与分层确认 |
| 状态与停止 | 缺配置、超时、取消、重启、修复上限等固定用例全部符合约定，轨迹与终态一致 |
| 证据与结构化输出 | 成功任务必需字段有效率、网格与检查/切片证据对应率均为100% |
| 延迟与资源 | 记录冷启动、推理、修复、检查耗时与峰值显存；累计活动执行不超过900秒，超时正确结束 |

轮廓IoU仅表示选定视角的轮廓一致性。有参考网格时补充归一化Chamfer Distance及刚性对齐、尺度依据，不用非等比形变降低误差。

## 3.修改前后对比与失败处理

- 对相同输入比较原始重建与完整工作流结果，记录尺度、缺陷、轮廓、文件可读和切片结果。
- 每轮固定数据版本和指标口径，保留全部失败任务；拒绝、不确定或未完成切片不能改为成功。
- 主分类使用项目规则中的数据、规则、工具、模型、状态、接口；显存不足可作为工具类子类，预处理或重建作为对应子类。
- 失败先写任务/Bug和预期行为，再补回归测试、修改实现；安全问题先停止相关能力并记录。
- 使用保留集结果改进后，将其改为已见回归集；需要新的未见集合才能再次报告泛化表现。

## 4.每轮评估记录模板

每次实际运行追加记录，不能覆盖上一轮：

| 字段 | 必填内容 |
| --- | --- |
| 评估身份 | 评估ID、日期、任务/阶段、操作者、是否真实运行 |
| 版本 | 数据集/样例清单、代码提交、模型及参数、执行机、依赖和打印配置 |
| 命令与证据 | 实际命令、输入、日志/报告路径、工具返回码、网格及修复版本 |
| 指标与阈值 | 定义、分子/分母、阈值、修改前值、修改后值、是否回归 |
| 失败样例 | case_id、预期/实际、分类、根因、Bug关联和处理决定 |
| 轨迹与成本 | 工具调用、证据支持情况、延迟、显存、token和费用；未知明确标记 |
| 复核与结论 | 人工复核人、范围与意见，达标项、未达标项和遗留限制 |
