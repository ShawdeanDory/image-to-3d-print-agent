# 本机双击生成与Blender预览

入口：[双击生成3D模型.cmd](../双击生成3D模型.cmd)。这是用户另行授权的LOCAL-001附属试用工具，P0验收结论保持不变，P1没有启动。

## 使用

1. 在当前项目文件夹双击`双击生成3D模型.cmd`。
2. 在选图窗口选择一张PNG/JPEG。优先单个物体、主体完整、轮廓清楚的图片；取消选择会直接退出。
3. 等待提示完成。透明PNG直接使用原有透明背景；普通图片在本机自动去背景。首次所需u2net权重已在本机下载，之后使用项目内缓存。
4. 成功后Blender会自动启动并导入模型。若出现Blender欢迎页，点击页面外关闭即可；鼠标中键拖动旋转、滚轮缩放。

每次结果位于项目`runs/manual/<时间与随机后缀>/`，保存原图副本、去背景图、模型输入图、`raw_mesh.glb`、过程日志和`run.json`；Blender导入证据为`blender_import.json`。原始图片及已有运行结果保持不变，运行产物不提交Git。

失败时控制台会保留错误和日志路径，按任意键关闭；成功后控制台自动关闭，Blender继续显示。一次只运行一个生成任务。缺少环境时不自动安装，不静默改用CPU重建；准备图片最多600秒、重建300秒、Blender导入120秒。

结果是原始近似网格，尚未定标或修复，不能直接当作已通过打印检查的成品。脚本在预览场景补偿坐标方向，不改写原始GLB。
