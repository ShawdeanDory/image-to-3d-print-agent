# P0入库证据摘要

执行编号`p0-20261018-01`。本目录保存安装前基线、原始失败数值、修改后几何检查、独立STL读取、切片和重建验证摘要；完整权重、网格和日志保留在本机被忽略的`weights/`、`runtime/`与`runs/p0/p0-20261018-01/`。
