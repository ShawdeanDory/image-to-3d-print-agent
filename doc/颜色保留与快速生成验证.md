# 颜色保留与快速生成验证

## 1.目标和边界

2026-10-21用户批准修复处理网格颜色、增加TRELLIS.2课程快速模式和实际分段计时。TripoSR保留官方基线；其单图厚度推测能力仍受输入和模型限制，不以几何拉厚或文字提示词假装解决。多图已按用户最新决定暂缓；不新增第三模型、视觉API、训练、保留集或自动关机。

原始PBR材质GLB保持；处理链用从纹理采样得到的顶点底色，简化后按同坐标系源顶点就近转移，属于外观近似，不宣称完整PBR保真。STL本身不携带这些显示颜色。旧任务文件和摘要不改写，新代码只影响后续生成与处理。

## 3.实现与接口

- BackendConfig和内部ReconstructCall增加course_fast；仅TRELLIS.2可用。CreateTask.reconstruction_profile为可选official/course_fast，默认null表示沿用服务端配置；公共1.0.0不变，runtime-v1兼容增补。profile随原任务/幂等请求保存，不能在恢复时临时切换。
- GET配置增加backend_profiles，前端只显示已配置后端的合法模式。官方完整入口保留原run.py/example.py；快速通过同一锁定源码/权重的pipeline和postprocess调用，不声称原封不动运行example.py。
- 快速参数：1024_cascade、seed42、目标100000面、2048纹理、remesh=true/band1/project0，不生成转台视频；实际面数以读回结果为准。
- model_worker.py在GPU同步后记录不重叠的加载准备、预处理、推理、原生保存、重网格/UV/纹理导出、独立读回和总时间。上游to_glb内部合并计时，不伪造更细阶段；Python启动另由execution.json记录。旧官方缺失分段仍未知。
- resources.reconstruction返回本任务实际模型记录，复用既有resources字典；页面显示已完成用时，不显示假进度。
- geometry/appearance.py负责纹理底色采样与简化后的近似转移；core.py、adapters/official.py、structure.py接入。Blender预览有真实顶点色时使用它，没有时保留明确的诊断蓝色。
