# 自动支撑与最终文件交付

2026-11-09。修改前基线`c44bf2c`。用户要求自动加支撑，网页只预览GLB，提供最终修复的GLB和带支撑STL下载。

## 交付逻辑

工作流在定标、最多2轮原有修复及复检之后导出最终彩色GLB和本体STL。几何通过后，CPU工具扫描从床面可达的悬垂位置，用现有打印配置的喷嘴口径确定柱宽和间距，以层高作为最小顶部间隙。工具用三角形与柱体水平范围的裁剪结果确定安全顶高，净空不足则跳过。导出重新读取三角面，核对本体及支撑柱几何。GLB只包含本体和原材质映射。

网页只预览通过几何复检的GLB。点击才下载。无需支撑时明确标注本体STL；几何未通过时保留质量报告，支撑工具失败时保留已通过几何复检的GLB并提示原因。历史任务不补写支撑记录，旧的本体STL接口继续兼容。

STL中的柱体是独立几何。PrusaSlicer的FDM自动支撑通常以切片路径存在，其含支撑STL导出功能属于SLA模式。[PrusaSlicer导出说明](https://help.prusa3d.com/article/export_1771)
